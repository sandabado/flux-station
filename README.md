# FluxStation Kids

An animated Next.js prototype for a father-son modular magnetic hex tile system.

## Run locally

```bash
npm install
npm run dev
```

Open <http://localhost:3000>. The interactive builder lives at `/configurator`.

## Included

- Animated, mobile-first marketing pages
- Drag-and-drop plus tap-to-place hex configurator
- Axial-coordinate snapping, live bundle pricing, local save, and share
- Shared cart with a slide-out drawer and quantity controls
- Metadata, sitemap, manifest, robots rules, and security headers

Checkout is deliberately presented as unwired. No payment request or deployment is included in this prototype.
